# Enterprise Autonomous IT Operations & Incident Resolution Agent

## Overview

An Agentic AI platform designed to monitor IT infrastructure,
investigate incidents, recommend or execute approved remediation,
verify recovery, and maintain incident audit records.

## Technology Stack

- Python
- FastAPI
- LangGraph (planned)
- Microsoft Azure integrations (planned)
- PostgreSQL (planned)
- Redis (planned)
- Automated testing with pytest
